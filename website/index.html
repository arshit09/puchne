Before you ask

Do I need API keys?

No. It types into the chat sites you're already signed in to.

Does it cost anything?

No. Free, MIT licensed, no paid tier.

Can it see my prompts?

Only to type them. No server, no analytics, nothing to send them to.

Not yet — install it in about a minute.
