New tabs mode

  1. Settings → Behavior

    Right-click the Puchne icon → Options.

  2. Opening Mode → New Tabs

    Grid-only options disappear.

  3. Turn on Group Tabs

    One tab group per send.

Ask from any page

  1. Select the text

    Nothing selected? It asks about the page.

  2. Right-click → Ask Puchne

    Or Ctrl + Shift + S.

  3. Choose the behaviour once

    In Settings → Ask Puchne: show the prompt, or send it directly.

Add your own tool

  1. Right-click the chat box → Inspect

    On the tool's own page, signed in.

  2. Copy something stable

    An id, then data-testid. Never a generated class name.

  3. Fill the form and press Test

    Settings → AI Tools → Add Custom AI Tool.

Change the shortcuts

  1. Settings → Global Shortcut

    Shows what's bound now.

  2. Click “Change Shortcuts”

    Or paste chrome://extensions/shortcuts — pages can't link there.

  3. Click the pencil, press your keys

    Pick Global to use it outside Chrome.

Nothing happens? Another extension may own that combination, or you're on a chrome:// page, the Web Store or a new tab — extensions can't run there.
