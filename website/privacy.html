What's collected

Nothing.

No personal data, no usage stats, no crash reports, no identifier, no prompt content. There is no server to send it to, and no third-party code in the extension. Verify it yourself — it's plain JavaScript with no build step.

Site access

Puchne declares no required website permissions.

At installAccess to zero websites.
Switching a tool onChrome asks for that one site. Decline and nothing else changes.
Any time afterWithdraw it from that tool's row in Settings.

That's why installing doesn't warn about “all your data on all websites” — until you hand it a site, it has none.

The AI sites themselves

Puchne changes how your text arrives — not what happens to it after.

Each service has its own policy and terms, which you agreed to with them. What they log, keep or train on is between you and them, exactly as if you'd typed it by hand.

Rule of thumb. Too sensitive to paste by hand = too sensitive to multicast. Sending to four tools means sharing with four companies.

Deleting it

DeleteWhere
Prompt historySettings → Maintenance → Clear History
All settingsSettings → Maintenance → Reset All
One site's accessThat tool's row in Settings → AI Tools
EverythingRemove the extension in chrome://extensions/

Anything already sent to an AI service follows that service's deletion process, not this one.

This website

Static HTML, one stylesheet, one script. No cookies, no analytics, no third-party fonts or scripts. It remembers one thing — your light/dark choice, in your own browser. The host may keep ordinary access logs, as any host does.
