Basics

What does it actually do?

Opens each AI site you picked, waits for the box, types your prompt, submits. Then shows the answers together.

Do I need API keys or a paid plan?

No. It uses the web chat pages you're already signed in to.

Is it free?

Free, MIT licensed, source on GitHub. No paid tier, no telemetry.

Which browsers?

Chrome 114+. Edge, Brave, Opera and Vivaldi load the same folder — sidebar docking depends on that browser's side-panel support. No Firefox or Safari build; no mobile.

Which AI tools?

ChatGPT, Claude, Gemini, Copilot, DeepSeek, Perplexity, Grok — plus any tool you add.

Chrome Web Store?

Not yet. Install takes about a minute.

Privacy

Can Puchne see my prompts?

Only to type them. No server, no analytics — nowhere to send them.

Why so few install permissions?

Because website access isn't requested at install. Each AI site is asked for separately, the first time you use that tool, and can be withdrawn.

Where does my history live?

Local storage in this browser profile. Not synced, not uploaded. Settings (never prompts) can ride your own Chrome sync.

Does it read the pages I visit?

Only where you granted access, and only to draw the overlay or read your selection.

What do the AI companies see?

What they'd see if you typed it yourself, under their own terms. Too sensitive to paste by hand = too sensitive for Puchne.

Using it

Grid or tabs?

Grid to compare, tabs to settle into one tool. Side by side →

Different tools just this once?

Tap the chips before you send.

Edit the prompt per tool?

Turn off Auto-Submit. Puchne fills each box and waits.

Does the follow-up reach tools I skipped?

No — only what's open. Send a fresh prompt to add one.

Pages where the overlay won't open?

chrome:// pages, the Web Store, the new tab page. Use the toolbar icon there.

The project

What does “Puchne” mean?

From the Gujarati પૂછવું (Puchhvu) — “to ask”.

Can I contribute?

Yes. Selector fixes are the most valuable — they keep everyone working when a site redesigns.

How do I check what it does?

Read it — plain JavaScript, no build step. The folder you load is the code that runs.

Affiliated with any AI company?

No. Independent and open source. Names and logos belong to their owners.
